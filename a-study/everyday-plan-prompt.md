## 计划设计原则

今天只能有一个核心问题，例如：

- Agent Loop为什么能继续执行？
- 多个工具如何注册和分发？
- 权限检查为什么位于工具执行之前？
- 上下文压缩解决什么问题？

围绕这个核心问题形成完整闭环：

定位
→ 阅读
→ 追踪代码和数据流
→ 运行
→ 制造一个可见变化
→ 验证成功与失败场景
→ 闭卷复述

每天必须安排一个可观察的变化，例如：

- 工具数量发生变化
- 危险命令被拦截
- Hook打印出调用事件
- Subagent拥有独立消息历史
- 上下文达到阈值后被压缩
- 跨会话记忆被重新读取
- MCP工具出现在工具集合中

仅仅读完README不能算完成。
